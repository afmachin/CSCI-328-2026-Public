Recorded output of two consecutive runs on the machine this course was built on
(2 cores visible to the JVM, OpenJDK 21). Your numbers will differ. The point is
the pattern, not the figures: parts one to three fail, part four does not, and the
size of the failure is not stable. An earlier run of this identical program on this
identical machine lost 6,165 of the 8,000 increments in part one. A defect this
variable is a defect you cannot test your way to.

$ cd reference/demos/race
$ javac RaceDemo.java && java RaceDemo
